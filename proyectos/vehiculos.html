Mi Garage Control

Aplicación web desarrollada con Python y Streamlit para gestionar el historial de mantenimiento de autos y motos. Permite registrar mantenimientos, reparaciones y costos, visualizar métricas mediante dashboards interactivos y anticipar próximos services según kilometraje. Actualmente se encuentra desplegada en Streamlit Community Cloud con persistencia PostgreSQL mediante Supabase.

Resumen

¿Qué problema resuelve?

Permite centralizar en un solo lugar el historial completo de cada vehículo, reemplazando anotaciones dispersas por un registro organizado de mantenimientos, reparaciones, mejoras, costos y próximos services estimados.

Funcionalidades principales

  • Registro y gestión de vehículos.
  • Diferenciación entre autos y motos.
  • Historial completo de mantenimientos, reparaciones y mejoras.
  • Registro y seguimiento de costos asociados.
  • Dashboard con métricas y gráficos interactivos.
  • Estimación automática de próximos services por kilometraje.
  • Alertas visuales según estado del mantenimiento.
  • Filtros por vehículo y estado de service.
  • Soporte bilingüe Español / Inglés.

Enfoque técnico

La aplicación utiliza PostgreSQL como capa de persistencia, alojada en Supabase, para mantener un historial consultable por vehículo. La lógica diferencia mantenimientos preventivos, reparaciones y mejoras, permitiendo analizar costos, consultar antecedentes y estimar próximos services a partir del kilometraje registrado.

Valor técnico

Qué demuestra este proyecto

Este proyecto demuestra el desarrollo completo de una aplicación web: modelado de datos, lógica de negocio, visualización de información, persistencia PostgreSQL y despliegue en la nube.

Competencias técnicas demostradas

  • Modelado de entidades y relaciones para vehículos y mantenimientos.
  • Persistencia y consultas sobre PostgreSQL mediante Supabase.
  • Desarrollo de interfaces web interactivas con Python y Streamlit.
  • Procesamiento y organización de datos con Pandas.
  • Visualización de métricas y gráficos interactivos con Plotly.
  • Migración de persistencia local SQLite a PostgreSQL.
  • Despliegue y publicación mediante Streamlit Community Cloud.
  • Versionado y mantenimiento del proyecto con Git y GitHub.

Aprendizajes

Durante el desarrollo evolucioné el proyecto desde una aplicación local basada en SQLite hacia una aplicación web desplegada en la nube, migrando la persistencia a PostgreSQL mediante Supabase. Esta evolución me permitió incorporar conceptos de despliegue, bases de datos remotas, arquitectura modular y publicación de aplicaciones web.
