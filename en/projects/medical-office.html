Medical Office Management System

Desktop application developed with Java and JavaFX to centralize patient management, medical records, studies and vaccinations. It uses SQLite for local data persistence and includes PDF document generation, database backups and tools designed for everyday medical office workflows.

Tech Stack

Java 21 · JavaFX · SQLite · Maven · PDF

Overview

What problem does it solve?

The system centralizes clinical and administrative patient information in a single application, reducing scattered records and providing easier access to medical history, studies, vaccinations and documentation.

Main Features

  • Patient registration and management.
  • Patient search and information updates.
  • Medical consultation and history management.
  • Medical study records.
  • Vaccination tracking.
  • PDF document generation.
  • Automatic database backups.

Technical Approach

Desktop application developed with Java 21 and JavaFX, using SQLite for local persistence through JDBC. The project separates the user interface, application logic and data access, while also incorporating data validation, PDF document generation and database backup mechanisms.

Technical Value

What This Project Demonstrates

An end-to-end project combining Java development, graphical user interfaces, SQL persistence, document generation and maintenance of an application used in a real-world environment.

Technical Skills Demonstrated

  • Desktop application development with Java and JavaFX.
  • Forms, tables and navigation between application views.
  • Local persistence using SQLite and JDBC.
  • Relational data modeling and queries.
  • Data validation and update workflows.
  • PDF document generation with iText.
  • Database backup mechanisms.
  • Dependency management and execution with Maven.

Development & Maintenance

The project originated from a real-world need and evolved through testing and everyday use. In addition to feature development, it involved Windows installation, environment configuration, troubleshooting, data maintenance and end-user support.
